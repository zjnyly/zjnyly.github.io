# Jianing Zheng · Personal Homepage

这是一个不依赖构建工具的静态个人主页，内容整理自 resume 和 papers。

本地预览：在仓库根目录运行 python3 -m http.server 8000 -d homepage，然后访问 http://localhost:8000。

GitHub Pages：将 homepage 目录中的内容复制到 zjnyly.github.io 仓库根目录，或将 GitHub Pages 的发布目录设置为 homepage。页面已经配置好 https://zjnyly.github.io/ 和 https://github.com/zjnyly 的链接。
