关于 / About

我是中山大学计算机科学博士研究生（硕博连读）。我的研究兴趣位于大语言模型、计算机体系结构与硬件加速的交叉地带，关注如何构建高效、可扩展且面向真实部署的模型推理系统。I am a Ph.D. student at Sun Yat-sen University. My research lies at the intersection of large language models, computer architecture, and hardware acceleration, with a focus on efficient and scalable inference systems for real-world deployment.

目前主要研究大语言模型推理加速、稀疏 Attention、长上下文推理、FPGA 加速器架构，以及模型—系统—硬件协同设计。My interests include LLM inference acceleration, sparse attention, long-context inference, FPGA accelerator architecture, and model–system–hardware co-design.

精选项目 / Selected projects

面向大语言模型高效推理的加速器设计 TeraflyEfficient Accelerator Design for LLM Inference

针对自回归解码导致加速器峰值算力欠饱和及单节点缺乏可扩展性的问题，提出混合时空架构，以空间架构提升细粒度吞吐，以时间架构实现计算资源复用。Proposed a hybrid spatial–temporal architecture to address compute under-utilization during autoregressive decoding and the limited scalability of a single accelerator node.

设计基于 HLS 的模板化代码生成框架，支持一键生成、并行扩展、环形组网与模块自动布局布线。端侧小模型 TPS 达到 GPU 的 1.1×，能耗优势达到 3.4×；相同资源下吞吐提升 50%。Built an HLS-based template generation framework for one-click code generation, parallel scaling, ring networking, and automatic placement and routing. Achieved 1.1× GPU TPS, 3.4× energy efficiency, and a 50% throughput gain at equal resource usage.

面向 1M Token 长上下文的存算侧 Attention 加速器设计 RheoAttentionMemory-Side Attention Acceleration for 1M-Token Contexts

设计解耦式 Memory-Side Attention 架构与 Cascaded Attention 三级空间流水，使片上 Attention 状态与上下文长度无关；FPGA 原型达到 99.42% INT2 输入带宽利用率和 99.94% DDR 带宽利用率。Designed a decoupled memory-side attention architecture and a three-stage cascaded spatial pipeline, achieving 99.42% INT2 input-bandwidth utilization and 99.94% DDR-bandwidth utilization on FPGA.

面向长程推理的 CPU–GPU 协同稀疏 Attention 推理系统 RheoServeCPU–GPU Collaborative Sparse Attention for Long-Context Inference

提出 Logical KV Cache、Compute Offload 与 Adaptive Block Migration，将 Host Memory 扩展为 Attention 执行层；在 RTX 3090 上 Qwen3-4B / 8B 峰值吞吐达到 236.5 / 137.2 tok/s，最高达到 2.13× 加速。Extended host memory into an attention execution layer with Logical KV Cache, Compute Offload, and Adaptive Block Migration. Reached 236.5 / 137.2 tok/s on Qwen3-4B / 8B and up to 2.13× speedup on an RTX 3090.

面向端侧小语言模型的细粒度结构化稀疏加速 RheoSparseFine-Grained Structured Sparsity for Small Language Models

提出支持任意 N:64 模式的结构化稀疏推理框架与 Bitmask SpMV Kernel；在 50% 稀疏率下平均准确率最高提升 4.80 个百分点，Decode 延迟最高降低 61.3% / 49.6%。Developed an arbitrary N:64 structured-sparsity framework and Bitmask SpMV kernel, improving average accuracy by up to 4.80 points at 50% sparsity and reducing decode latency by up to 61.3% / 49.6%.
