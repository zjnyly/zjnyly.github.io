02 / Selected Work

精选项目 Selected Projects

面向真实推理瓶颈的代表性研究工作，覆盖 FPGA 加速、长上下文 Attention 与端侧结构化稀疏。

PROJECT 01 · TERAFLY

面向大语言模型高效推理的加速器设计

Efficient Accelerator Design for LLM Inference

针对自回归解码导致加速器峰值算力欠饱和及单节点缺乏可扩展性的问题，提出混合时空架构，以空间架构提升细粒度吞吐，以时间架构实现计算资源复用。

设计基于 HLS 的模板化代码生成框架，支持一键生成、并行扩展、环形组网与模块自动布局布线。端侧小模型 TPS 达到 GPU 的 1.1×，能耗优势达到 3.4×；相同资源下吞吐提升 50%。

PROJECT 02 · RHEOATTENTION

面向 1M Token 长上下文的存算侧 Attention 加速器设计

Memory-Side Attention Acceleration for 1M-Token Contexts

设计解耦式 Memory-Side Attention 架构与 Cascaded Attention 三级空间流水，使片上 Attention 状态与上下文长度无关；FPGA 原型达到 99.42% INT2 输入带宽利用率和 99.94% DDR 带宽利用率。

PROJECT 03 · RHEOSERVE

面向长程推理的 CPU–GPU 协同稀疏 Attention 推理系统

CPU–GPU Collaborative Sparse Attention for Long-Context Inference

提出 Logical KV Cache、Compute Offload 与 Adaptive Block Migration，将 Host Memory 扩展为 Attention 执行层；在 RTX 3090 上 Qwen3-4B / 8B 峰值吞吐达到 236.5 / 137.2 tok/s，最高达到 2.13× 加速。

PROJECT 04 · RHEOSPARSE

面向端侧小语言模型的细粒度结构化稀疏加速

Fine-Grained Structured Sparsity for Small Language Models

提出支持任意 N:64 模式的结构化稀疏推理框架与 Bitmask SpMV Kernel；在 50% 稀疏率下平均准确率最高提升 4.80 个百分点，Decode 延迟最高降低 61.3% / 49.6%。
